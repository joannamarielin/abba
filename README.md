# Adventures with Babe 🎂 (Arseniy's 32nd Birthday Edition)

A bespoke, responsive web application crafted to celebrate **Arseniy's 32nd Birthday**, featuring **42 curated adventures** across San Francisco and within a 2-hour drive.

---

## 🌟 How to Open & Run the App

No installation or build steps required! Simply open the app in any web browser:

1. **Option 1 (Direct Open)**: Double-click `index.html` or drag it into Google Chrome, Safari, or Arc.
2. **Option 2 (Local Server)**: Run the following in your terminal:
   ```bash
   ruby -run -e httpd . -p 8000
   ```
   Then open `http://localhost:8000` in your browser.

## 🛠️ App Features & Controls

1. **Birthday Adventure Roulette ("Surprise Us!")**:
   - Randomizes your next date idea matching your active filters with a slot machine animation and confetti celebration.
2. **Passport Progress Tracker**:
   - Tracks your progress toward completing 32 adventures for Arseniy's 32nd birthday.
   - Unlocks milestone badges (*Sunset Chaser*, *Burger Connoisseur*, *Naomi's Animal Hero*, *Master Crafter*, *SF Night Owl*, and *Level 32 Legend*).
3. **Personal Date Journal & Memory Keeper**:
   - Record completion dates, 1-to-5 star ratings, private date notes, and upload memory photos saved directly in browser `localStorage`.
4. **Interactive Dual View (Grid & Leaflet Map with CARTO Basemaps)**:
   - Toggle between responsive cards and an interactive map powered by your **CARTO Basemaps API key**.
   - Includes a custom layer switcher in the top right allowing you to toggle between:
     - 🌅 **CARTO Voyager**: Warm golden-hour daylight palette.
     - 🌃 **CARTO Dark Matter**: Sleek nighttime aesthetic perfect for city lights and raves.
     - ✨ **CARTO Positron**: Crisp minimalist view.
5. **Weekend Date Itinerary Planner**:
   - Bundle 2–3 adventures into a weekend timeline with one-click clipboard copying or printing.
6. **Custom Adventure Creator**:
   - Add your own newly discovered secret spots anytime!
